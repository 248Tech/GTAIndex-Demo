Friends not showing up?
  • Everyone needs GTAIndex open. The app is only "online" while it's running.
  • The first time it runs, Windows asks about network access. Choose Allow for Private networks. If you clicked Cancel, allow GTAIndex.exe in Windows Defender Firewall.
  • Your Wi-Fi must be set as a Private network. Public networks block discovery.
  • Guest Wi-Fi and some routers isolate devices from each other. Add friends by address instead, or use Tailscale.
