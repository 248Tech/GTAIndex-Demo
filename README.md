# GTAIndex: live demo

> **Fan Project.** GTAIndex is an unofficial, fan-made field guide for Grand Theft Auto VI. It is not affiliated with, endorsed or sponsored by Rockstar Games or Take-Two Interactive. Grand Theft Auto and all related names, images and trademarks belong to their respective owners.

**Open the demo:** https://248tech.github.io/GTAIndex-Demo/

GTAIndex is an offline desktop app (a single Windows `.exe`). This repo holds a static web build of it so you can try it in the browser:

- an interactive Leonida map with filters, search and directions
- a database of characters, vehicles, weapons, items and safehouses
- guides, a Discover feed and collectibles checklists
- a progress tracker (Save, Plan visit, Mark complete, or Mark acquired for weapons)

In this demo, progress is saved in your browser only. **Crew**, which shares progress live with friends on the same network, needs the desktop app.

This repo contains generated output only. The app's source code is private.
